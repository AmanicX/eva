Everything Answered

Frequently asked questions.

Straightforward answers about privacy, model pricing, local inference, and open-source architecture.

Where is my personal conversation data stored?

Strictly on your local machine. In desktop apps, data is saved directly in your local application data folder. In the web version, data resides in your browser's IndexedDB. Eva does not operate any central database or cloud proxy.

Can I use Eva completely offline without an internet connection?

Yes. The desktop edition connects natively to Ollama and LM Studio running on localhost (127.0.0.1). When using local models, zero bytes leave your local computer.

Do I have to pay for Eva?

Eva is completely free and open-source under the MIT license. You only pay your AI provider (e.g. Groq, OpenRouter) directly if you use paid cloud models. Free providers (Pollinations, Google AI Studio free tier) are also supported.

How are my API keys secured?

API keys are never stored in unencrypted application state. On desktop, keys are encrypted via Electron safeStorage (OS keychain). On Android, keys are encrypted via hardware-backed AES keys in Android Keystore.

How do the three universes differ from each other?

Chatbot is a clean, focused AI studio. Anime introduces stylized avatars, emotional responses, and voice synthesis. Living World is an interactive RPG universe where places, factions, and reputation persist across scenes.
